# VOXGAURD_V8

Full-stack application for audio processing and voice modeling.

## Architecture
- `backend/`: FastAPI implementation for API and model orchestration.
- `frontend/`: Frontend application (placeholder).
- `mobile/`: Mobile application code (placeholder).
- `models/`: ML model definitions and configurations.

## Setup
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   npm install
   ```
2. Run backend: `uvicorn backend.main:app --reload`
